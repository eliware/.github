# Eliware

Eliware builds developer tools and software projects across Node.js libraries, Discord applications, and Model Context Protocol (MCP) tooling.

## Explore our work

Eliware maintains public tools, libraries, and applications.

- [@eliware/discord](https://github.com/eliware/discord): A modular Discord app framework for Node.js with slash commands, localization, and event-driven support.
- [@eliware/errors](https://github.com/eliware/errors): Process-level handlers for uncaught exceptions, unhandled rejections, and warnings.
- [@eliware/log](https://github.com/eliware/log): Structured ESM logging for Node.js with redaction and defensive serialization.
- [Knit](https://github.com/eliware/knit): GitHub webhook handling and SSH deployment automation with Discord notifications.

Browse [public Discord framework guides](https://github.com/eliware/discord/tree/main/docs) for setup, usage, configuration, and API details.

[Browse all Eliware repositories](https://github.com/orgs/eliware/repositories).
