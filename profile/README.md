# Eliware

Eliware builds developer tools and software projects across Node.js libraries, Discord applications, and Model Context Protocol (MCP) tooling.

## Explore our work

- [MCP Server](https://github.com/eliware/mcp-server) — a Node.js server for building MCP APIs with dynamic tools, HTTP access, and authentication.
- [Discord](https://github.com/eliware/discord) — a modular Node.js framework for Discord applications, slash commands, localization, and events.
- [OpenAI](https://github.com/eliware/openai) — an OpenAI API client wrapper for Node.js with ESM and TypeScript support.
- [AgentX CLI](https://github.com/eliware/agentx-cli) — a terminal chat agent using the OpenAI Responses API over WebSocket.

Browse [all Eliware repositories](https://github.com/orgs/eliware/repositories).
